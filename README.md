# MovieLens 1M Recommender System

Реализация рекомендательной системы на датасете MovieLens 1M с выполнением полного цикла: подготовка данных, исследовательский анализ, построение моделей, оценка качества и сравнение подходов.

## 1. Датасет

Используется набор MovieLens 1M, включающий:

- ~1 000 000 оценок
- 6 040 пользователей
- 3 900 фильмов
- шкала оценок: 1–5
- временные метки
- жанры
- демографические данные пользователей

Данные не размещаются в репозитории и должны быть загружены отдельно.

## 2. EDA (Exploratory Data Analysis)

Основные наблюдения:

- матрица взаимодействий крайне разреженная (~99.9 %)
- большинство пользователей ставят менее 50 оценок
- большинство фильмов получают менее 20 оценок
- выраженная проблема cold start, особенно для фильмов
- распределение жанров неравномерное (лидирующие: Drama, Comedy, Action)
- активность пользователей имеет сезонность по дням недели и часам суток

Преобразования включают:

- построение словарей user_id → index и movie_id → index
- разбиение train/test по времени
- построение матрицы взаимодействий

Ноутбук: notebooks/01_eda_and_preprocessing.ipynb

## 3. Построенные модели

В проекте реализованы три подхода:

### 3.1 Item-based kNN

Метод коллаборативной фильтрации по схожести фильмов на основе пересечения пользователей.

Плюсы:

- использует взаимодействия

Минусы:

- чувствителен к разреженности
- плохо работает при малых пересечениях

### 3.2 Content-based

Контентная модель на основе жанров фильмов. Для фильмов вычисляется косинусное сходство по one-hot представлению жанров.

Плюсы:

- не требует пересечения пользователей
- устойчив к разреженным данным

Минусы:

- качество ограничено богатством контента

### 3.3 Гибридная модель

Объединяет баллы kNN и content-based через взвешивание:

score = α * content + (1 - α) * knn

Использовался α = 0.5.

Ноутбук: notebooks/02_modeling.ipynb

## 4. Метрики

Оценка проводится по метрикам ранжирования:

- Recall@K
- MAP@K
- NDCG@K

Метрики рассчитываются по Top-K рекомендациям на тестовой части.

## 5. Результаты

Оценка выполнена при K = 10.

| Модель         | Recall@10 | MAP@10 | NDCG@10 |
|----------------|----------:|-------:|--------:|
| Item-kNN       | 0.00158   | 0.00138 | 0.00666 |
| Content-based  | 0.01512   | 0.01209 | 0.03107 |
| Hybrid         | 0.01130   | 0.00888 | 0.02459 |

Выводы:

- Content-based показал наилучшие результаты на данном датасете
- Item-kNN значительно деградирует из-за разреженности
- Hybrid улучшает разнообразие рекомендаций и частично закрывает недостатки kNN

## 8. Заключение

Реализована базовая рекомендательная система с тремя подходами. На данном наборе данных модели, основанные на контенте, работают лучше коллаборативных из-за разреженности матрицы взаимодействий и проблемы отсутствия пересечений между пользователями.

Направления развития:

- добавление текстовых признаков (описания, актёры, режиссёры)
- использование эмбеддингов (TF-IDF, BERT)
- применение имплицитных сигналов (просмотры, клики)
- латентные модели (Matrix Factorization, LightFM, NeuMF)
- модели ранжирования (LambdaRank / XGBoost)
- двухбашенные модели retrieval и ranking
